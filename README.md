# Ollama Chat UI 💬

Простой и быстрый веб-интерфейс для общения с локальными моделями через **Ollama**.

## 🚀 Особенности
- **Стриминг текста**: Ответы появляются постепенно, как в ChatGPT.
- **Контекст**: Приложение запоминает историю сообщений в рамках текущей сессии.
- **Сохранение истории**: Все чаты сохраняются локально в JSON-файлах, позволяя переключаться между ними и удалять историю.
- **Конфигурация**: Модель по умолчанию настраивается через файл `.env`.
- **Безопасность**: Приложение доступно только на `localhost`.
- **Управление**: Используется современный менеджер пакетов `uv`.

## 🛠 Стек технологий
- **Python 3.14+**
- **Streamlit** (Веб-интерфейс)
- **Ollama** (Запуск моделей)
- **uv** (Менеджер зависимостей и виртуальных окружений)

## 📋 Инструкция по установке и запуску

### 1. Требования
Убедитесь, что у вас установлены:
- [Ollama](https://ollama.ai/) (запущена и загружена модель, например `ollama run llama3`)
- [uv](https://github.com/astral-sh/uv) (менеджер пакетов Python)

### 2. Клонирование и установка
```bash
# Клонируйте репозиторий
git clone <url_репозитория>
cd ollama-chat-ui

# Установите зависимости
uv sync
```

### 3. Настройка модели
Создайте файл `.env` в корневой директории на основе `env.example` и укажите модель по умолчанию:
```text
OLLAMA_MODEL=llama3
```

### 4. Запуск
Вы можете запустить приложение напрямую:
```bash
./run.sh
```
Или через Streamlit:
```bash
uv run streamlit run app.py
```
После запуска откройте в браузере: `http://localhost:8501`

## 📂 Структура проекта
- `app.py`: Главный файл интерфейса Streamlit.
- `src/`: Основная логика приложения (обработка запросов, взаимодействие с Ollama).
- `.env`: Файл конфигурации.
- `run.sh`: Скрипт для быстрого запуска проекта.

## ⚙️ Конфигурация
- **Модель**: Можно изменить в файле `.env` или через интерфейс.
- **Очистка истории**: Кнопка в боковом меню позволяет сбросить контекст диалога.
